== What each permission string means ==
-rwxr-x--- (750) scripts/prepare_data.sh : owner can read, write and run it; group datateam can read and run it but not change it; everyone else has no access.
-rw-r----- (640) clean/*.csv              : owner can read and write; group datateam can only read; everyone else has no access.
-r--r--r-- (444) raw/*                    : everybody can read, nobody (not even the owner) can write - the originals stay safe.
owner / group columns (root datateam)     : the file belongs to user root and to group datateam; analyst is a member of datateam, so analyst gets the group permissions.
